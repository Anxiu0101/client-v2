## Mermaid 流程图

```mermaid
flowchart TB
    subgraph Source["内容源"]
        MDX_FILES["content/\n  tech/**/*.mdx\n  life/**/*.mdx\n  book/**/*.mdx"]
        CAT_YML["content/categories/*.yml"]
        TAG_YML["content/tags/index.yml"]
    end

    subgraph Velite["Velite 构建"]
        SCHEMA["Schema 校验"]
        COMPUTED["计算字段\n(slug, permalink, category)"]
        MDX_PARSE["MDX 解析\n(rehypeSlug, rehypePrettyCode,\nremarkMermaid, remarkAlert)"]
        PREPARE["prepare 钩子\n(search-index.json)"]
    end

    subgraph Output["构建产物"]
        VELITE_DIR[".velite/\n  posts.json\n  categories.json\n  tags.json"]
        SEARCH_JSON["public/search-index.json"]
    end

    subgraph Consumer["消费端"]
        SSR["服务端组件"]
        CSR["客户端组件\n(CommandSearch)"]
    end

    MDX_FILES --> SCHEMA
    CAT_YML --> SCHEMA
    TAG_YML --> SCHEMA
    SCHEMA --> COMPUTED
    COMPUTED --> MDX_PARSE
    MDX_PARSE --> PREPARE
    PREPARE --> VELITE_DIR
    PREPARE --> SEARCH_JSON
    VELITE_DIR --> SSR
    SEARCH_JSON --> CSR
```

## Mermaid 时序图

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant B as 后端
    participant D as 数据库

    U->>F: 点击搜索
    F->>B: GET /api/search?q=keyword
    B->>D: SELECT * FROM posts WHERE ...
    D-->>B: 返回结果
    B-->>F: JSON 响应
    F-->>U: 渲染搜索结果
```

## Alert 告警框

### Python

```python
from datetime import datetime
from typing import List


class BlogPost:
    def __init__(self, title: str, tags: List[str]):
        self.title = title
        self.tags = tags
        self.created_at = datetime.now()

    def summary(self) -> str:
        return f"{self.title} [{', '.join(self.tags)}]"
```
